# ismb-ai

Applied AI for business · Customer analytics · Recommendation systems · Forecasting

I worked on Python applications and experiments at **Makes**, translating transaction data into customer and product analysis, recommendation workflows and demand-forecasting models.

## Selected work

| Project | What to explore |
| --- | --- |
| [Customer analytics & CRM intelligence](https://github.com/ismb-ai/customer-analytics-crm) | RFM segmentation, retention indicators, ABC analysis and Streamlit business dashboards |
| [Recommendation systems](https://github.com/ismb-ai/recommendation-systems) | Collaborative filtering, neural models, autoencoders and hybrid recommendation experiments |
| [Demand forecasting](https://github.com/ismb-ai/demand-forecasting) | Temporal windows, SVR, random forests, ARIMA and recurrent neural-network experiments |

Each repository includes a source tour, a small example using synthetic data, behavioural checks, data expectations and modelling limitations. The [complete source archive](https://github.com/ismb-ai/makes-ai-archive) preserves the earlier project versions and provenance.

**Technical areas:** Python, pandas, NumPy, scikit-learn, TensorFlow/Keras, Streamlit, exploratory analysis, customer segmentation and time-series modelling.

Historical prototypes are labelled as such, original team credits are retained, and private business datasets are excluded.
